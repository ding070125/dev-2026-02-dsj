# 项目名称

## 项目简介

这是一个使用 JavaScript 完成 API 交互与数据渲染的任务面板页面。

## 我完成的功能

- 获取任务列表（页面加载自动获取、手动刷新获取）
- 渲染任务列表（支持空数据、加载中、异常状态的提示）
- 提交新任务（包含输入验证、防重复提交、提交结果提示）
- 按状态筛选任务（支持“全部/待开始/进行中/已完成”筛选）
- 错误提示（网络异常、接口失败、输入错误等场景的友好提示）
- 安全处理（HTML 转义防止 XSS 攻击）

## 我的实现思路

### 1. 页面加载

页面 DOM 加载完成后，自动调用 `fetchTasks` 函数请求任务列表接口，同时为“刷新任务”按钮、筛选下拉框、提交表单绑定对应的事件监听，初始化全局变量 `allTasks` 存储所有任务数据（用于后续筛选）。

### 2. 获取和渲染数据

- **获取数据**：通过 `fetch` 发送 GET 请求到任务列表接口，处理 HTTP 状态异常、接口返回失败、网络异常等场景，分别展示对应的提示文案；请求过程中禁用“刷新任务”按钮，避免重复请求。
- **渲染数据**：接口返回成功后，将数据存入 `allTasks`，调用 `renderFilteredTasks` 进行筛选后渲染；渲染时通过 `map` 遍历任务数据生成 DOM 结构，对任务标题/负责人做 HTML 转义防止 XSS；同时根据任务数量展示“共 X 个任务”或“暂无任务数据”的提示。
- **加载状态**：请求过程中展示“加载中...”提示，请求完成后更新提示文案和样式。

### 3. 提交任务

- **表单拦截**：监听表单提交事件，阻止默认刷新行为，通过 `FormData` 获取表单输入值并做.trim() 处理。
- **输入验证**：检查任务名称和负责人是否为空，为空则展示红色错误提示。
- **防重复提交**：提交请求时禁用提交按钮和刷新按钮，请求完成（成功/失败）后恢复按钮状态。
- **发送请求**：通过 `fetch` 发送 POST 请求，设置 `Content-Type: application/json`，将任务数据转为 JSON 字符串传递；根据接口返回的 `success` 状态展示成功/失败提示，成功后重置表单并刷新任务列表。
- **提示处理**：提交结果提示保留 3 秒后自动清空，提升用户体验。

### 4. 状态筛选

- 监听筛选下拉框的 `change` 事件，触发 `renderFilteredTasks` 函数。
- 根据下拉框选中值（`all/todo/doing/done`），对 `allTasks` 进行过滤：选中“全部”则保留所有数据，否则筛选出对应状态的任务。
- 将筛选后的任务列表传入 `renderTasks` 函数，重新渲染页面。
